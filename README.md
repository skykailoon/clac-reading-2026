# CLAC 新人陪读 2026 版

根据《CLAC 新人陪读 2026 版》制作的中文静态阅读网站。

- 首页为五个单元的目录。
- 点击单元后只显示该单元的完整内容。
- 保留教导、经文及陪伴导读与互动问题。
- 米白与浅棕暖色，适配电脑及手机。

## 使用

下载所有文件到同一个文件夹，打开 `index.html` 即可阅读，无需安装依赖。

## 文件

- `index.html`：网页入口
- `style.css`：页面样式
- `app.js`：目录与单元切换
- `content.js`：完整单元内容
